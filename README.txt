BA Euroflyer Destination Intelligence PWA

Changes in this version:
- Wind speed is displayed in mph.
- Arrival flow / processing estimate section removed.
- Added baggage belt lookup by flight number.

Baggage belt note:
Baggage belt/carousel data is controlled by each destination airport and is not available from one universal free public API for all BA Euroflyer destinations. The app provides per-flight lookup/search buttons and a manual confirmed belt field for operational use once confirmed from the airport arrivals feed.

Install/use:
Run from HTTPS or a local web server. PWA installation will not work from a plain file:// link.
